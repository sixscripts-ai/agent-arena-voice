# Agent Arena UI Directions

## 1. Arena Frequency

![Arena Frequency preview](/manus-storage/agent-arena-preview-arena-frequency_41b2d4a3.png)

This direction extends the strongest parts of the LiveKit-inspired branch: graphite surfaces, cyan signal accents, fixed artifact readers, and quiet realtime movement. It is best when the product should feel like an **evidence console** for technical users. The final UI would use cyan only for active runtime state, focus rings, and explicit action emphasis.

## 2. Precision Grid

![Precision Grid preview](/manus-storage/agent-arena-preview-precision-grid_bbddac1c.png)

This is an editorial, light-mode alternative built around modular grids, blue decision points, and carefully ranked evidence. It is the strongest choice if Agent Arena should lead with **clarity, formats, and research credibility**, rather than a live-operations mood. It will keep battle pages compact and legible when artifacts are dense.

## 3. Match Broadcast

![Match Broadcast preview](/manus-storage/agent-arena-preview-match-broadcast_dd285202.png)

This direction treats every battle as a serious, observable event. It gives the phase timeline, current model state, and judge decision much more visual gravity. It is best when the product should make **live competition** feel immediately compelling without becoming a generic esports interface.

## Shared Non-Negotiables

All directions preserve evidence-first mechanics: bounded event activity, fixed-height artifact inspectors, clear phase states, judge provenance, and visible model/battle status. None should add fabricated scores, testimonials, or fake live records.

## Local Selector

The interactive selector is available in the local Voice application at `http://localhost:3000/ui-directions`. It presents the three options side-by-side, uses rendered preview cards if a generated image is unavailable, and stores the current choice locally in the browser for review before frontend implementation begins.
